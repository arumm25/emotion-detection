# Emotion Detection

This repository contains an emotion detection application built as part of the final project. The application analyzes text input and identifies emotion scores such as anger, disgust, fear, joy, and sadness using the Watson NLP library.

## Project Details

- Project Name: Emotion Detection
- GitHub User: arumm25
- Repository: emotion-detection
- Main Feature: Analyze text and return the dominant emotion
- Framework: Flask
- Language: Python

## Application Function

The application receives text input from the user, sends the text to the emotion detection service, and returns the emotion scores along with the dominant emotion.
